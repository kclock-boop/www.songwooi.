삼목기업 저장소의 기업소개형 허브 구성을 참고하여 송우산업의 기업·제품·공정·연혁과 8회 컨설팅 계획 및 자료실을 연결했습니다.

## 기업소개 홈페이지

삼목기업처럼 밝은 배경, 둥근 메뉴, 네이비 대표 화면과 오렌지 강조색, 역량·제품·연혁·운영체계·자료실·연결 메뉴로 구성합니다. 대표 호스 그림은 제조와 데이터 연결 개념도이며 실제 제품·현장 사진이나 방문 증빙이 아닙니다.

## 컨설팅 자료

공정전문가 8회 계획은 진단에서 목표·시스템·실행계획과 사업계획서까지 연결합니다. 1회차는 2026-09-14 방문 전 예정 초안입니다. 실제 수행내용·날짜·시간·공정전문가 성명·사진·서명은 확인 후 수정해야 합니다. 협약기간은 자료 간 차이가 있어 서명된 협약을 확인합니다.

## 자료 기준

2024 회사소개서, KSA 2026-09-08 절차 안내 및 최신 260913 제공 8회 일정표. 과거 인증 이력은 현재 인증 유효성을 뜻하지 않습니다. 원본 내부자료·개인정보·납세·소득·계좌 증빙은 게시 파일에 포함하지 않습니다.

## 수행일지 작성 기능

대시보드 오른쪽 상단의 수행일지 작성에서 1~8회차별 근무일자·시간·담당자·전문가·주요 내용·수행업무내용·차기 일정을 기록하고 사진 2장을 첨부할 수 있습니다. 사용자 제공 기업마크를 오른쪽 상단에 표시합니다.

- 이 회차 임시저장 및 불러오기: 현재 브라우저에 보관
- 백업 파일 저장 및 불러오기: JSON 파일로 기록과 사진 보관·복원
- 인쇄 미리보기: 공식 양식의 기본정보·본문·사진·차기 일정 확인
- 인쇄 및 PDF 저장: 브라우저 인쇄 화면에서 PDF 저장 선택

기록·사진은 서버나 GitHub로 전송하지 않으며 다른 기기와 자동 동기화되지 않습니다. 서명·날인은 인쇄 후 실제 확인을 받습니다. 공개 저장소에는 입력 없는 작성 화면과 기업마크만 게시됩니다.


## DX·스마트공장 구축 사전 설문

[사전 설문 열기](https://kclock-boop.github.io/www.songwooi./docs/dx-survey/)

`docs/dx-survey/`의 독립 정적 페이지입니다. 참고 설문지의 기업정보 → 진단 → 결과 → 컨설팅 가이드 흐름을 송우산업의 압출·성형·호스 검사·재공재고·LOT 추적 업무에 맞게 재구성했습니다. 홈페이지에서도 진입할 수 있습니다.

- 5개 영역 × 4문항의 준비도 진단, 경영환경과 구축 요구사항 15문항, 응답자 정보 및 영역별 근거 메모
- 문항별 0~4점, 영역별 유효응답 평균을 100점 환산한 후 5개 영역 동일 가중 평균. 20문항 응답 및 각 영역 2개 이상 유효점수일 때만 종합점수 표시
- 모름·해당 없음은 점수에서 제외. 공식 스마트공장 수준·사업 선정 점수와 구분
- 현재 브라우저 임시저장/불러오기, JSON 내보내기/검증 후 가져오기, 읽기용 TXT 보고서, 전체 응답 인쇄/PDF, 초기화
- 미응답 및 데이터·현장 검증·보안 준비에 따라 확인 과제를 표시. 인쇄 때 긴 입력 내용을 펼쳐 출력

응답·개인정보는 서버나 GitHub에 전송하지 않습니다. 사용자가 저장한 파일을 담당 컨설턴트에게 별도로 전달합니다. 다른 기기와 자동 동기화하거나 관리자에게 자동 제출하는 기능은 없습니다. 원본 PDF와 기업 내부자료는 게시하지 않습니다. 중앙 수집이 필요하면 승인된 별도 저장소와 접근권한·제출 동작을 설계해야 합니다.

설문 내용은 `questions.js`, 동작은 `app.js`, 화면은 `index.html`·`style.css`에서 수정할 수 있습니다. 서버·외부 라이브러리·빌드가 필요하지 않습니다. 2026년도 공고는 준비사항 설계에만 참고했으며 차기 공고의 조건을 확정하지 않습니다.
