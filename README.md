## 기업소개 홈페이지

삼목기업처럼 밝은 배경, 둥근 메뉴, 네이비 대표 화면과 오렌지 강조색, 역량·제품·연혁·운영체계·자료실·연결 메뉴로 구성합니다. 대표 호스 그림은 제조와 데이터 연결 개념도이며 실제 제품·현장 사진이나 방문 증빙이 아닙니다.

## 컨설팅 자료

공정전문가 8회 계획은 진단에서 목표·시스템·실행계획과 사업계획서까지 연결합니다. 1회차는 2026-09-14 방문 전 예정 초안입니다. 실제 수행내용·날짜·시간·공정전문가 성명·사진·서명은 확인 후 수정해야 합니다. 협약기간은 자료 간 차이가 있어 서명된 협약을 확인합니다.

## 자료 기준

2024 회사소개서, KSA 2026-09-08 절차 안내 및 최신 260913 제공 8회 일정표. 과거 인증 이력은 현재 인증 유효성을 뜻하지 않습니다. 원본 내부자료·개인정보·납세·소득·계좌 증빙은 게시 파일에 포함하지 않습니다.

## 수행일지 작성 기능

대시보드 오른쪽 상단의 수행일지 작성에서 1~8회차별 근무일자·시간·담당자·전문가·주요 내용·수행업무내용·차기 일정을 기록하고 사진 2장을 첨부할 수 있습니다. 사용자 제공 기업마크를 오른쪽 상단에 표시합니다.

- 이 회차 임시저장 및 불러오기: 현재 브라우저에 보관
- 백업 파일 저장 및 불러오기: JSON 파일로 기록과 사진 보관·복원
- 인쇄 미리보기: 공식 양식의 기본정보·본문·사진·차기 일정 확인
- 인쇄 및 PDF 저장: 브라우저 인쇄 화면에서 PDF 저장 선택

기록·사진은 서버나 GitHub로 전송하지 않으며 다른 기기와 자동 동기화되지 않습니다. 서명·날인은 인쇄 후 실제 확인을 받습니다. 공개 저장소에는 입력 없는 작성 화면과 기업마크만 게시됩니다.


## DX·스마트공장 구축 사전 설문

[사전 설문 열기](https://kclock-boop.github.io/www.songwooi./docs/dx-survey/)

`docs/dx-survey/`의 독립 정적 페이지입니다. 참고 설문지의 기업정보 → 진단 → 결과 → 컨설팅 가이드 흐름을 송우산업의 압출·성형·호스 검사·재공재고·LOT 추적 업무에 맞게 재구성했습니다. 홈페이지에서도 진입할 수 있습니다.

- 5개 영역 × 4문항의 준비도 진단, 경영환경과 구축 요구사항 15문항, 응답자 정보 및 영역별 근거 메모
- 문항별 0~4점, 영역별 유효응답 평균을 100점 환산한 후 5개 영역 동일 가중 평균. 20문항 응답 및 각 영역 2개 이상 유효점수일 때만 종합점수 표시
- 모름·해당 없음은 점수에서 제외. 공식 스마트공장 수준·사업 선정 점수와 구분
- 현재 브라우저 임시저장/불러오기, JSON 내보내기/검증 후 가져오기, 읽기용 TXT 보고서, 전체 응답 인쇄/PDF, 초기화
- 미응답 및 데이터·현장 검증·보안 준비에 따라 확인 과제를 표시. 인쇄 때 긴 입력 내용을 펼쳐 출력

응답·개인정보는 서버나 GitHub에 전송하지 않습니다. 사용자가 저장한 파일을 담당 컨설턴트에게 별도로 전달합니다. 다른 기기와 자동 동기화하거나 관리자에게 자동 제출하는 기능은 없습니다. 원본 PDF와 기업 내부자료는 게시하지 않습니다. 중앙 수집이 필요하면 승인된 별도 저장소와 접근권한·제출 동작을 설계해야 합니다.

설문 내용은 `questions.js`, 동작은 `app.js`, 화면은 `index.html`·`style.css`에서 수정할 수 있습니다. 서버·외부 라이브러리·빌드가 필요하지 않습니다. 2026년도 공고는 준비사항 설계에만 참고했으며 차기 공고의 조건을 확정하지 않습니다.


## 2026-09-17 설문 응답 예비분석

[분석 보고서 열기](https://kclock-boop.github.io/www.songwooi./docs/dx-analysis/2026-09-17/) · [Markdown 원문](docs/dx-analysis/2026-09-17/report.md)

사용자가 제공한 응답 1건을 재계산했습니다. 계산값은 0/100이지만 20문항 모두 동일 선택, 서술형 9개 항목에 ‘1’만 기재되어 실제 기업 수준 판정은 보류했습니다. 관심사항, 응답 품질, 현장 확인 순서, 품질예측 과제 후보, KPI 정의와 후속 실행계획을 제안합니다. 원본 응답 JSON은 공개 저장소에 추가하지 않았습니다.


설문 준비도 결과는 5단계로 표시합니다: 0~20점 미만 기초 정비, 20~40점 미만 데이터 수집·표준화, 40~60점 미만 시스템 연계·현장 활용, 60~80점 미만 예측·최적화 실증, 80~100점 지속 개선·고도화. 공식 스마트공장 수준과는 다릅니다. 기존 JSON도 불러올 수 있으며 결과는 현재 기준으로 재계산합니다. 새 JSON의 result에는 stage와 scoringVersion(2)이 포함됩니다.


## 설문결과 대시보드

[대시보드 열기](https://kclock-boop.github.io/www.songwooi./docs/dx-dashboard/)

종합 5단계, 영역별 막대·문항 상세, 응답 품질, 관심사항과 후속 과제를 한 화면에서 확인합니다. 기본 화면은 2026-09-17 공개 예비분석 요약이며 기업 수준 확정값이 아닙니다. `응답 JSON 불러오기`로 현재 기기의 새 응답을 분석할 수 있습니다. 파일은 서버로 전송하거나 영구 보관하지 않으며 새로고침하면 공개 요약으로 돌아갑니다. 인쇄·PDF 저장을 지원합니다.

설문과 대시보드는 `docs/dx-survey/scoring.js`를 함께 사용합니다. 가져온 파일의 기존 result는 사용하지 않고 answers를 검증·재계산합니다. 서술형 부족 판정은 빈 값·단순 숫자·미정 등 패턴에 대한 보완 안내이며 내용의 사실성 검증은 아닙니다.

대시보드 색상은 송우산업 공식 홈페이지(http://www.songwooi.co.kr/css/style.css)의 블루 `#174eaa`, 딥블루 `#063291`, 포인트 `#db0025`를 참고했습니다. 5개 진단 영역은 블루·청록·보라·오렌지·핑크로 구분하며, 색상은 영역 식별용이고 실제 점수·단계는 문구와 수치로 표시합니다.


## 문항별 AS-IS / TO-BE 해석

20개 진단 문항에 쉬운 현장 질문, 실제 선택한 답변(AS-IS), 확인할 문제 가설, 현재 수준에 맞춘 구체적인 목표 상태(TO-BE), 우선 실행, 확인자료, 측정지표와 협의부서 제안을 연결했습니다. 설문에서 답변을 고르면 다음 목표가 바로 표시되고 자세한 해석을 펼칠 수 있습니다. 대시보드에서는 개선 확인 후보 3개와 전체 20문항의 개선표를 확인·다운로드할 수 있습니다.

- 점수 0~3은 문항별 다음 수준의 구체적 개선을 제안하고, 4점은 현재 체계 유지·변경 후 검증을 제안합니다.
- 미응답·모름·해당 없음은 결함으로 단정하지 않고 현황·적용 여부 확인으로 안내합니다.
- 확인 후보는 낮은 점수 순, 동점이면 희망과제와 관련된 문항 순입니다. 투자효과·비용 순위가 아닙니다.
- 공개 예비응답의 가설성, 작성된 근거의 미검증 상태를 유지합니다. 수치 목표나 확인되지 않은 원인을 임의로 제시하지 않습니다.
- `diagnosis.js`와 `diagnosis.css`를 설문·대시보드가 공유합니다. TXT와 JSON의 interpretation에도 문항별 해석을 포함합니다. 점수 산식은 동일합니다.
