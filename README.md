# 송우산업 기업소개 및 제조DX AX기획 컨설팅

삼목기업 저장소의 기업소개형 허브 구성을 참고하여 송우산업의 기업·제품·공정·연혁과 8회 컨설팅 계획 및 자료실을 연결했습니다.

## 생산본부 AX 추진 대시보드

[대시보드 열기](https://kclock-boop.github.io/www.songwooi./docs/production-ax/)

회사소개 2024 4쪽 생산본부 조직을 기준으로 생산1팀·생산2팀·물류자재팀의 AX 후보과제를 연결합니다. 팀 필터, KPI 입력 계산, 예시 적용·초기화와 데이터 준비도 점검을 제공합니다. 실제 실적 연동 전이며 제안 역할은 기업 승인 전입니다. 개인정보·원본 문서·현장사진을 추가 게시하지 않습니다.

## 기업소개 홈페이지

삼목기업처럼 밝은 배경, 둥근 메뉴, 네이비 대표 화면과 오렌지 강조색, 역량·제품·연혁·운영체계·자료실·연결 메뉴로 구성합니다. 대표 호스 그림은 제조와 데이터 연결 개념도이며 실제 제품·현장 사진이나 방문 증빙이 아닙니다.

## 컨설팅 자료

공정전문가 8회 계획은 진단에서 목표·시스템·실행계획과 사업계획서까지 연결합니다. 1회차는 2026-09-14 방문 전 예정 초안입니다. 실제 수행내용·날짜·시간·공정전문가 성명·사진·서명은 확인 후 수정해야 합니다. 협약기간은 자료 간 차이가 있어 서명된 협약을 확인합니다.

## 자료 기준

2024 회사소개서, KSA 2026-09-08 절차 안내 및 최신 260913 제공 8회 일정표. 과거 인증 이력은 현재 인증 유효성을 뜻하지 않습니다. 원본 내부자료·개인정보·납세·소득·계좌 증빙은 게시 파일에 포함하지 않습니다.
