# 송우산업 제조DX AX기획 컨설팅

공정전문가 8회 수행계획과 1회차 예정 수행일지를 연결한 자료 허브입니다.

- `site/index.html`: 기업·공정 소개와 컨설팅 계획
- `docs/downloads`: 편집 가능한 Word와 PDF
- `proposal`: 계획 및 현장 기록 자료

1회차는 방문 전 예정 초안입니다. 실제 수행 확인 후 제출용으로 수정합니다. 협약기간과 공정전문가 성명은 확인 필요입니다. 자료 기준은 2024 회사소개서, KSA 2026-09-08 안내 및 최신 260913 제공 8회 일정표입니다. 개인정보·납세·소득·은행 증빙과 원본 내부자료는 게시 파일에 포함하지 않았습니다.

배포: GitHub Pages의 main 브랜치 루트 폴더를 선택합니다.
