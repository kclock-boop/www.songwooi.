Executive summary

ERP, MES, SCM, 그룹웨어 등 기본 정보시스템을 보유하고 있지만 종합 추진계획, 투자효과 분석, 교육, 보안, 데이터 분석 인력과 DX 역할체계가 부족합니다.

02 / SYSTEM

03 / EXECUTION

Strength & gap

강점과 취약점을
같은 화면에서 봅니다

확인된 강점

  • 경영진의 정보화 관심과 지원 의지가 높음
  • ERP 자체 구축, MES·SCM·그룹웨어 등 보유
  • 그룹웨어의 부서 간 공유 활용
  • 품질개선과 생산운영 개선 우선순위가 명확
  • 스마트팩토리·DX·ERP 교육 수요가 명확

주요 취약점

  • 종합 정보화 추진계획과 투자효과 분석 없음
  • 최근 정보화·DX 교육 미실시
  • 정보보안 계획과 통합 탐지체계 부족
  • 데이터 분석 전문가와 DX 역할체계 없음
  • 시스템 보유 대비 생산·공정·품질 활용이 낮음
