# 송우산업 정보화수준 조사표

사용자 제공 「2025년 중소기업 정보화수준조사 조사표.pdf」(15쪽)를 웹 입력 도구로 재구성했습니다.

- 원본 A~D의 39개 문항(하위 문항 포함), 기업 기본정보, 응답자·면접원 항목을 수록했습니다.
- C11의 21개 정보시스템 항목과 원본에 지정된 사내·기업간 활용 범위를 반영했습니다.
- 2024년 실적 / 2025년 추정 / 2025년 6월 30일 인력 기준을 유지합니다.
- B1 투자금액은 원본의 원 단위 자리표 대신 백만원 단위로 입력합니다. 1백만원 미만 지출은 1을 입력합니다. B2-1 교육비는 만원 단위입니다.
- 공식 배점 기준이 제공되지 않아 점수나 등급을 계산하지 않습니다. 작성률은 조건에 따라 적용되는 입력항목의 응답 비율입니다.

## 사용

1. 회사명 외에는 실제 자료를 확인하여 입력합니다.
2. 응답 점검으로 미응답, 순위 중복, 인원 합계, 자체수행·아웃소싱 합계 등을 확인합니다.
3. 브라우저 저장 또는 JSON 파일 저장으로 보관합니다. 자동 서버 제출은 없습니다.
4. CSV 응답표와 인쇄/PDF로 담당자에게 전달할 수 있습니다.

브라우저 저장본에는 인적사항을 포함합니다. 파일 내보내기·인쇄는 기본적으로 응답자·면접원 영역 전체를 제외하며, 체크박스를 선택하면 포함합니다. JSON은 이 조사표의 전용 형식이며 기존 20문항 DX 설문 JSON과 호환되지 않습니다. 브라우저 데이터 삭제 시 저장본도 없어질 수 있으므로 JSON으로 백업합니다.

## 조건 처리

- 지사·영업소·부설공장: 원본 기준 종료.
- B2 교육 미실시: 교육실적 생략. 없음·미이용은 단독 선택.
- B8 도입계획: 미도입 시 응답. B9-1: 유지보수 1·2 응답 시 표시.
- C10 자체수행+아웃소싱=100%; 도입·확대 계획이 있을 때 이유 표시.
- C11 해당업무 없음·미구축은 활용 항목 생략. 기업간 활용은 1~10번만 제공.
- D2-1은 D2 3~5, D4-1은 선택한 솔루션, D5-1은 교육 실시·계획 시 표시.
- B3·D8·D9는 3순위, D3는 최대 2순위. D8 7번은 단독 선택.
- 비활성화된 응답은 저장·내보내기·인쇄에서 제외됩니다.

## 구현과 확인

외부 라이브러리·서버·분석 추적기를 사용하지 않는 HTML/CSS/JavaScript입니다. `index.html`, `data.js`, `app.js`를 같은 폴더에 둡니다. 사용자 입력은 textContent로 출력하고 CSV 수식 실행 문자를 무력화합니다. JSON은 스키마·선택지·숫자 범위를 확인한 후 한 번에 복원합니다.

원본 39개 문항의 포함 여부, 198개 필드 ID 중복, 선택지 번호, 조건 분기, 복수응답 제한, 순위·인원·비율 검사, 저장·복원, JSON/CSV 다운로드, 잘못된 JSON 입력 보존, 인적사항 제외, 모바일 가로 넘침, 인쇄와 JavaScript 오류 여부를 점검했습니다.
